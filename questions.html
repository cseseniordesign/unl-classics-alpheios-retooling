Getting Started

Welcome to Arethusa Lite! This is a lightweight treebanking tool for syntactic annotation. Use the navigation buttons at the top to move between sentences, or select a specific sentence from the dropdown menu.


Navigation

First/Last buttons: These double arrows allow users to jump to the first or last sentence in your document.

Previous/Next buttons: These single arrows move one sentence backward or forward.

Sentence selector: Choose any sentence directly from the dropdown.


Editing the Tree

Changing heads: Click on a dependent node, then click on its new head to create the relationship.

Relations: Use the relation tool in the sidebar to modify dependency relations.

Morphology: Click the morph tool and then any word node to edit morphological attributes of selected tokens.


View Options

Compact/Expand: Adjust the spacing of the tree visualization.

Focus root: Center the view on the root of the sentence.

Focus selection: Center the view on the currently selected node.

Center: Reset the view to the center of the tree.

Table view: Switch to a tabular representation of the sentence.


Saving Your Work

Click the green Save button located first in the toolbar at the top right of the screen or use the hot key "Ctrl + s". The system will also autosave when changes are made to the tree,indicated in the lower right of the tree.


Troubleshooting

If the tree doesn't display correctly, try using the Center button to reset the view.

If you experience issues, use the Exit button to return to the main menu and try reloading the document.
