Getting Started

Welcome to Arethusa Lite! This is a lightweight browser-based dependency treebanking editor for ancient and modern languages. To begin, go to the input page and either paste raw text or upload an existing ALDT XML file. Select your language and text direction, then click Edit to open the editor. Use the Advanced Options panel to choose an annotation tagset, configure a custom tokenization service, or load two files for tree comparison.

Navigation

First/Last buttons: The double arrows jump to the first or last sentence in your document.

Previous/Next buttons: The single arrows move one sentence backward or forward.

Sentence selector: The dropdown lists all sentences in the file along with a preview of their contents — choose any sentence directly.

Editing the Tree

Morphology (Morph tab): Click the Morph tab, then click any word token. The morphology panel will populate, if the language is supported, attributes are fetched from the Morpheus API. Adjust the POS and attribute dropdowns as needed and confirm. Click the cog icon for additional options: Preselect assigns every word a morphology from the service's first choice (sentence navigation will be disabled while preselect is taking place to avoid unwanted behavior). Alternate Morph allows input of alternate morphology microservice URLs.

Dependency relations (Relation tab): Click the Relation tab, then click the intended child word. Select the label and the arc updates immediately. Click the cog icon to enable Advanced Mode, which lets you assign the same relation to multiple selected words at once. You can also click Highlight Unassigned, this will highlight all words that have not been assigned a relation tag

Artificial tokens (aT tab): Click the aT tab to add a token that is not in the original text. Enter the word, select its insertion point, and click Add token.

Undo / Redo: The undo and redo buttons in the header reverse or replay structural edits in order. Note that undo and redo only affect structural changes to the tree, not other edits.

Working with Sentences

Selecting batches of words (Selector tab): Click the Selector tab and enter a token, form, or label to search by. Matching words across the document are highlighted; click any to deselect them from the batch.

Merging sentences (Sentence tab): Click the Sentence tab, select the sentence to append to the current one, then click Merge sentences.

Splitting sentences (Sentence tab): Click the Sentence tab, select the word that should be the last word before the split, then click Split sentences.

Hotkeys

Esc: Clears the current selection, including batch selections. Does nothing if a modal is open.

W: Moves the selection forward to the next word. If nothing is selected, starts at the first word. Wraps around to the first word after reaching the end of the sentence. Disabled when a modal is open, the XML tab is active, or a batch selection is active.

E: Moves the selection backward to the previous word. If nothing is selected, starts at the last word. Wraps around to the last word after reaching the beginning of the sentence. Disabled when a modal is open, the XML tab is active, or a batch selection is active.

1: Opens the Morph tab.

2: Opens the Relation tab.

3: Opens the aT tab.

4: Opens the Selector tab.

5: Opens the Sentence tab.

6: Opens the XML tab.

Ctrl+Z / Cmd+Z: Undo the last structural edit.

Ctrl+Shift+Z / Cmd+Shift+Z: Redo the last undone structural edit.

Ctrl+S / Cmd+S: Save the current treebank as an XML file.

Right-click (tree node): Opens a mini menu to change the relation label of a node. Also includes shortcut buttons to disconnect the node or connect it directly to the root, where applicable. On a trackpad, use a two-finger click.

XML Editing

Click the XML tab in the sidebar, then click Edit XML to view and hand-edit the raw ALDT XML for the current sentence. Make your changes and click Confirm. The XML tool includes schema validation via WebAssembly (xmllint) to catch errors before they are applied.

View Options

Table view: Switch between the interactive tree visualization and a tabular representation of the sentence data.

Tree comparison: Load two ALDT XML files side-by-side from the Advanced Options panel on the input page (or via the compare button in the header). Differences in head assignments or relation labels are highlighted on the right tree. Each tree can be navigated independently. Scroll down from the trees (or click the Table button) to view an empirical difference table — sentence numbers are colored green if identical and red if any inconsistency exists; clicking a number jumps both trees to that sentence.

Saving Your Work

Every edit is automatically saved to localStorage — look for the autosave indicator in the lower right of the tree. To download a permanent copy, click the Save (floppy disk) button in the header toolbar, or use Ctrl+S. This exports the current treebank as an .xml file. Be sure to save before exiting — the Exit button will prompt you to confirm, but unsaved work not yet downloaded will be lost if localStorage is cleared.

Using Compare Mode

Compare mode lets you check your treebank against an instructor's reference tree and see exactly where your annotations differ. To enter compare mode, click the Compare button in the header toolbar and enter the 6-digit code provided by your instructor. If the code matches a reference tree, the editor will switch into compare mode immediately.

While in compare mode the Compare Mode panel appears on the right side of the screen in place of the usual tool tabs. All tool tabs are disabled and the tree is read-only meaning you cannot move nodes, change relations, or open context menus. You can still navigate between sentences normally using the header buttons or the sentence selector, and the comparison highlights update automatically as you move through the document.

To leave compare mode and resume editing, click the Exit Compare Mode button inside the Compare Mode panel.

What the visual markers mean:

  • Red highlighted word: The word's lemma does not match the instructor's reference. The background rectangle behind the word form is filled red.
  • Red highlighted postag: The word's postag does not match the instructor's reference. The background rectangle behind the postag above the word is filled red.
  • Thick red dependency arc: The word's head assignment is wrong. It is attached to a different parent than in the instructor's tree. The arc leading to that word is drawn in red with a heavier stroke weight.
  • Red highlighted relation: The dependency relation label on an arc does not match the instructor's label for that word. The label text itself is highlighted red; the arc may otherwise appear correct if the head is right.

A single word can show multiple markers at once if more than one attribute is wrong. Words with no markers are in full agreement with the instructor's reference for that sentence.

Supported Languages and Tagsets

Arethusa Lite supports Greek, Latin, English, Persian, Arabic, and more. Available annotation tagsets include ALDT (Latin and Greek), Universal Dependencies, Smyth Grammar, JMH Ancient Greek, Harrington, Wheelock, Pedalion, and beta support for Persian, Lyon Latin, and Lyon Greek

Troubleshooting

Chrome or Edge are recommended. Firefox and Safari have known issues with downloading XML smoothly.

If the tree doesn't display correctly, try the Center button to reset the view.

If you experience persistent issues, click the Exit button to return to the input page and try reloading your document. Confirm exit when prompted, and ensure any work you want to keep has been downloaded first.

Adding an Instructor Tree

To add a new tree to the instructor set, prepare a valid treebank XML file with the standard root element and set its code attribute to a unique 6-digit numeric string (e.g. code='004217'). This is the code you will distribute to students. Place the completed file in the instructorTrees/ folder at the project root, then open app/treebanking/ui/compareModal.js and add the file's basename to the INSTRUCTOR_TREE_FILES array near the top of the file (e.g. 'MyPassage_TEACHER.xml'). That one-line addition is all that is required; the modal will fetch and search the new file automatically the next time a student enters a matching code. The header line should look something like: <treebank xml:lang="grc" version="1.5" direction="ltr" format="morphgrc" code='000000'></treebank>
